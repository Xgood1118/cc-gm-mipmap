在现有 mip 骨架上，把它做成一个合格的 mipmap 生成器。保留 Image、load_png、save_png、
downsample、generate_chain 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，
不得改动 data/texture.png。

## 需要完成

1. **降采样质量**
   - 每一级都要做区域平均，不能只取单个源像素。
   - 半透明边缘不能出现黑边，透明度要一起降采样。
   - 第二级之后，四个象限的色块边界仍要可分辨，判据写进 README。

2. **非 2 次幂尺寸**
   - 200x120 的输入要能生成尺寸规整的链，最后一级为 1x1，中间每一级的宽高关系要在 README 里写清。
   - 不能出现某一维先归零的情况。

3. **级数与空洞**
   - 支持指定最大级数，超过就截断。
   - 1x1 输入要给出合理的级数，不能返回空链或者抛异常。

4. **输出**
   - 每一级一张 PNG，文件名要能看出级数。
   - 同一输入连续跑两次，所有输出逐字节相同。

5. **测试**
   - 覆盖：尺寸序列、区域平均（构造 2x2 四色图验证）、透明边缘不混黑、级数截断、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m mip.cli data/texture.png --out-dir out`，把每级的尺寸、每级四个象限的
平均色贴进 README。
