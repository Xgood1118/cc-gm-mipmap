# mipmap 链生成器

纯 Python 标准库实现：读写 8 位 RGBA PNG（读取支持全部 5 种行过滤类型），
用 2x2 区域平均逐层降采样，直到 1x1。

## 降采样规则

- **区域平均**：每个目标像素对源图中对应的 2x2 区域取平均；奇数尺寸的边缘
  自动裁剪为 2x1 / 1x2 / 1x1，不会丢弃行列，也不会只取单个源像素。
- **透明度预乘**：RGB 按 alpha 加权平均（`sum(c*a)/sum(a)`），alpha 单独取算术
  平均。半透明边缘不会把透明像素的 RGB（通常是黑）混进来；全透明区域输出
  `(0,0,0,0)`。
- **色块边界判据**：把每级图按几何中点分成四个象限，计算各象限 RGB 平均色，
  两两之间的最大通道差应 ≥ 30。测试贴图在 4x2（第 6 级）及之前均满足，
  即第二级之后色块边界依然可分辨（见下方实测表）。

## 非 2 次幂尺寸

每级宽、高分别取 `ceil(上级 / 2)`，即 `(n + 1) // 2`。因此：

- 奇数维度收敛路径为 `n → (n+1)/2 → … → 1`，任何一维都不会先归零；
- 宽、高各自独立减半，链在两个维度都到 1 时才结束，最后一级恒为 1x1；
- 200x120 的完整尺寸序列为：
  `200x120 → 100x60 → 50x30 → 25x15 → 13x8 → 7x4 → 4x2 → 2x1 → 1x1`（共 9 级）。

## 级数

- 默认生成到 1x1；`--levels N`（或 `generate_chain(img, max_levels=N)`）截断到
  N 级，N < 1 会抛 `ValueError`。
- 1x1 输入返回仅含原图的单级链，不为空、不抛异常。

## 输出

- 每级一张 PNG，写入 `out/level_00.png`、`level_01.png`……，编号即级数。
- 写出固定使用过滤类型 0、zlib 压缩级别 9，不嵌入任何时间戳，同一输入连续
  跑两次输出逐字节相同（有测试覆盖）。

## 运行

```
python gen_samples.py          # 重新生成测试贴图（可选，仓库已带）
python -m mip.cli data/texture.png --out-dir out
python -m pytest tests -q
```

测试贴图 200x120，四个象限四种颜色，叠了斜向渐变，用来检验降采样是否保留
色块边界。

## 实测：data/texture.png 各级尺寸与四象限平均色

`python -m mip.cli data/texture.png --out-dir out` 生成 9 级。下表为每级按几何
中点划分的四象限 RGB 平均色（顺序：左上、右上、左下、右下；`—` 表示该象限
在此尺寸下无像素）：

| 级 | 尺寸 | 左上 | 右上 | 左下 | 右下 |
|---|--------|---------------|---------------|---------------|---------------|
| 0 | 200x120 | (120, 32, 32) | (43, 131, 65) | (45, 72, 144) | (194, 169, 67) |
| 1 | 100x60  | (120, 32, 32) | (43, 131, 65) | (45, 72, 144) | (194, 169, 67) |
| 2 | 50x30   | (120, 32, 32) | (43, 131, 65) | (45, 72, 144) | (194, 169, 67) |
| 3 | 25x15   | (118, 31, 31) | (47, 127, 64) | (50, 69, 137) | (180, 163, 71) |
| 4 | 13x8    | (114, 34, 38) | (55, 131, 65) | (46, 72, 146) | (193, 169, 72) |
| 5 | 7x4     | (114, 34, 38) | (56, 133, 66) | (46, 72, 146) | (196, 171, 72) |
| 6 | 4x2     | (100, 54, 43) | (56, 143, 70) | (76, 92, 129) | (209, 182, 73) |
| 7 | 2x1     | — | — | (88, 73, 86) | (133, 163, 72) |
| 8 | 1x1     | — | — | — | (111, 118, 79) |

第 0–2 级象限平均色完全一致（200、100、50 均为偶数，2x2 块不跨象限边界），
第 3 级起奇数尺寸让块跨越边界、颜色开始轻微混合，但直到 4x2 四象限两两
最大通道差仍远大于 30，色块边界可分辨。
